## Posting checklist

### Instagram — carousel
1. New post → select `images/01.png` through `images/06.png` **in order**.
2. Keep the default 4:5 crop (the files are already 1080 × 1350).
3. Paste the Arabic caption. Add the English version as the first comment if
   you want bilingual reach.
4. Add the WhatsApp link in bio, or use the link sticker in a story that
   reshares the post.

### Instagram — reel
1. Upload `video/dukkani-voice-reel.mp4` as a Reel. It already has the Arabic
   voiceover, so **keep the original audio** (no trending track needed).
2. Choose `frames/reel-1.png` as the cover (it is already 1080 × 1920).
3. Paste the short Arabic caption.

### Facebook — carousel
1. Create post → add the six images in order.
2. Paste the Arabic caption. Facebook will show them as a swipeable gallery.
3. Put the WhatsApp link in the first comment (Facebook down-ranks link posts).

### Facebook — reel
1. Upload `video/dukkani-voice-reel.mp4` as a Reel (original audio on).
2. Pick the cover, paste the short caption.

### Stories
- Reshare the reel, or post slides 1, 4, and 6 as three story frames.
- Add a link sticker to the WhatsApp URL above.
